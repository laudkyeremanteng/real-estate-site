# 🏠 Delta Homes Ghana - Luxury Real Estate Website

A premium real estate website showcasing luxury properties in Ghana with modern design and conversion-focused features.

## 🚀 Quick Start Guide

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Run Development Server
```bash
npm run dev
```

### Step 3: Open Your Browser
Navigate to [http://localhost:3000](http://localhost:3000)

## 📋 Project Setup Checklist
